# 課題・工程判定の記録

初めて人間に確認する時点で、[課題管理表テンプレート](../workflow/issue-tracking/references/template.md) から、このフォルダに `issue-log.md` を作成する。以後、全工程の確認事項・決定・反映確認を同じ課題 ID で記録する。記録と更新は [課題管理 Skill](../workflow/issue-tracking/SKILL.md) に従う。

[フェーズゲート](../documents/phase-gates.md) は、着手時の確認範囲、通過・保留の判定、理由、確認資料の版を `phase-gates.sqlite3` に作業 ID・工程ごとに記録する。判定を確認する場合はフェーズゲートの `status` を実行する。
