# Compass の作業後報告

依頼の完了条件と、成果物・差分・検証結果を照合する。次の５項目を毎回この順で報告する。該当する事項がない項目は「なし」と記載する。

1. **作業結果**
2. **実施した検証と結果**
3. **未実施の検証と理由**
4. **未確認事項**
5. **次に推奨する作業**

実施した検証の対象と結果、未実施の理由、判定できない範囲を区別する。証跡の粒度や複数の検証結果の扱いに迷った場合は、[報告項目と判定基準](references/reporting.md) を参照する。

必須項目の内容・根拠が未記録の場合は、工程を未完了として、欠けている項目を作業結果と未確認事項に記載する。

今回に関係する確認待ちの課題は「未確認事項」、対応待ちの課題は「作業結果」の残作業に課題 ID を添える。状態の判定は [課題管理 Skill](../issue-tracking/SKILL.md) を参照する。

「次に推奨する作業」には残作業や未確認事項に対応する具体的な操作を記載する。追加作業が不要な場合は「追加作業なし」と記載する。
