# RDCの通常作業

導入先のプロジェクトルートで `AGENTS.md` と `.compass/README.md` を読み、そこから `.compass/workflow/README.md` と今回の依頼に該当するSkill・ガイドを参照する。作業前の４項目の表示から作業後の報告まで、導入先のワークフローに従う。

`.compass/README.md` が存在しないプロジェクトでRDCの利用を依頼された場合は、[セットアップSkill](../compass-setup/SKILL.md) を実行する。
