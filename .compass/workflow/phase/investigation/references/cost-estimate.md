# サービス別コスト試算テンプレート

[計算式付きExcelテンプレート](cost-estimate.xlsx) を案件用に複製して使う。比較案 A〜D には、クラウド各社、自社設備、AI API、SaaS、外部サービス、ライセンス、保守・運用工数などを組み合わせられる。試作・通常月・繁忙月の使用量で、月額、年間運用費、初年度総額を比較する。集計は円・税抜。

## 料金の調査と登録

1. 比較する対象処理・必要な機能・使用量を揃える。サービスのリージョン、プラン・SKU、課金項目、単位、適用条件を確認する。
2. 公式料金表、公式料金計算ツール、見積書で単価を確認する。料金台帳に課金項目ごとに１行で入力し、元の通貨・根拠の参照先・確認日を記録する。保存容量、読み取り・書き込み、転送などは必要な項目ごとに登録する。
3. 使用量シートの同じ料金 ID で、前提から使う数量か直接入力の数量を指定する。１回単価なら換算数量は `1`、1,000回単価なら `1000`。地域が指定されない契約は地域欄に「共通」と記録する。

| 提供元の例 | 料金の確認先 |
| --- | --- |
| AWS | [AWS Pricing Calculator](https://calculator.aws/) ・ [Amazon S3 の料金](https://aws.amazon.com/s3/pricing/) |
| Microsoft Azure | [Azure 料金計算ツール](https://azure.microsoft.com/pricing/calculator/) ・ [Azure Retail Prices API の項目](https://learn.microsoft.com/en-us/rest/api/cost-management/retail-prices/azure-retail-prices) |
| Google Cloud | [Google Cloud 料金計算ツール](https://cloud.google.com/products/calculator) ・ [Cloud Storage の料金](https://cloud.google.com/storage/pricing) |
| その他のクラウド・外部基盤 | 対象サービスの公式料金表。例として [Cloudflare R2 の料金](https://developers.cloudflare.com/r2/pricing/) |
| SaaS・ライセンス・外部API・運用保守 | ベンダーの料金表、見積書、契約書、社内の時間単価。例として [GitHub のプラン別料金](https://github.com/pricing) |

## Excelの入力と集計

| シート | 使う項目 |
| --- | --- |
| 前提 | 比較案の表示名、試作期間、繁忙月数、通貨ごとの円換算係数、試作・通常・繁忙それぞれの共通使用量 |
| 料金台帳 | 比較案 ID、提供元、サービス、地域・条件、SKU・プラン、課金項目・周期・単位、原通貨単価、通貨、根拠・確認日 |
| 使用量 | 料金 ID に対する数量元、換算数量、段階ごとの下限・上限、各ケースの直接数量、初期数量 |
| 計算内訳・試算結果 | 円換算単価、課金数量、費目別・比較案別の費用、根拠の確認件数 |

- 使用量は AI 入力・出力トークン、サーバー・GPUの台時間、電力・容量・転送量、席数、処理回数、保守工数などを前提から選べる。構成固有の数量は「直接入力」で記録する。
- 一部数量まで無料なら、課金行の段階下限に付帯数量を指定する。段階ごとに単価が異なる場合は、同じ課金項目を複数行に分け、各料金帯の下限・上限を入力する。課金数量は、上限までの使用量から下限を控除した数量。丸め・最低料金・割引などがある場合は、公式条件で換算した数量や見積明細を入力する。
- 月次料金は月の課金数量×円換算単価。年額単価は12で割って月換算する。初期費用は初期数量×円換算単価。「前提」の繁忙月数を変えると通常月数も変わる。年間運用費は通常月額×通常月数＋繁忙月額×繁忙月数、初年度総額は年間運用費＋初期費用。
- 未登録の比較案は「未登録」、計算に必要な値が不足する場合は「要確認」。試算表は40件の料金明細に対応する。未評価の費目と料金条件は調査報告書に記録する。

## 入力例

同じ比較案でストレージとチーム用ライセンスを使う例。月の使用量は保存100 GB-month、ライセンス３席。換算レートは計算例として１ USD＝150円。単価と料金条件には確認した公式ページを記録する。

| 料金 ID | サービス・条件 | 原通貨単価 | 使用量 | 月額の計算例 |
| --- | --- | --- | --- | --- |
| R01 | Cloudflare R2 Standardの保存。無料枠10 GB-monthを適用 | 0.015 USD／GB-month | 100 GB-month | (100−10)×0.015×150＝202.50円 |
| R02 | GitHub Teamの席 | 4 USD／席・月 | ３席 | ３×４×150＝1,800円 |

２明細を同じ比較案 ID に登録すると、通常月額に2,002.50円が集計される。料金出典は [R2 の料金・無料枠](https://developers.cloudflare.com/r2/pricing/) と [GitHub のプラン別料金](https://github.com/pricing)。

## 調査報告書に記録する項目

「実現可能性の比較」に、試算ブックの版、対象期間、使用量、採用した料金の根拠、未評価の費目を記録する。

| 比較案 | 試作期間の運用費 | 通常月額 | 繁忙月額 | 年間運用費 | 初期費用 | 初年度総額 | 試算ブック・根拠の参照先 |
