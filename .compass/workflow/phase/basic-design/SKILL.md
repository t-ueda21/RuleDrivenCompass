# 基本設計

作業範囲に「基本設計」が含まれるときに適用する。

## 成果物テンプレート

[基本設計書テンプレート](references/template.md) を使って、担当範囲の成果物を作成・更新し、記録項目を確認する。レビューでは対象の成果物をテンプレートの項目と照合する。

テンプレートの必須欄に確認した内容または根拠の参照先を記録する。補足欄にも内容または適用結果と理由を記録する。完了前は[共通の記録・確認ルール](../../../documents/document-records.md)に沿って全項目を確認する。

## 実施手順

1. 対象の要件と既存の基本設計書を確認し、主要な構成要素の責務と、今回変更する境界を特定する。
2. 各境界で、どの構成要素からどの構成要素に何を渡すか、どの条件で何を返すかを契約として定める。
3. 基本設計書の該当箇所を作成・更新する。結合試験で確認する契約を項目名または ID で参照できるようにする。

## 必須項目

- 設計目的、設計範囲、対応する要件
- 主要な構成要素と責務、接続先
- 要素間の契約が今回の設計に関係する場合は、呼び出し元と相手、入力・前提条件、応答、異常時の扱い、仕様の版・参照先、確定状況
- 設計の確認結果と根拠。未確定事項がある場合は、後続工程への影響と対応予定を記録する。

## 詳細な確認

構成変更、要素間の契約、連携条件、互換性への影響を確認するときは、[基本設計の確認基準](references/checkpoints.md) を参照する。

## 完了条件

対象の要件に対して構成・責務・接続が決まり、設計の確認結果を根拠と照合できる。対象の契約が確定し、結合試験で各境界の期待結果を決められる。
