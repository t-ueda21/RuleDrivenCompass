# 結合試験の確認基準

- **判定根拠。** 基本設計の契約 ID・項目名と、試験で接続する要素の組合せを照合する。画面と API、API と DB、別サービスなど、確認した接続を特定する。
- **観測対象。** 呼び出しの応答だけでなく、データの受け渡しや更新、相手側に生じる副作用が契約どおりかを確認する。
- **異常・再試行。** タイムアウトをどこで発生させるか、何を再送するか、再試行で重複してはならない結果は何かを、該当する契約から設定する。
- **実環境と代替。** 接続先を代替した場合は、実際に検証した組合せと、実サービスで未確認の契約を記録する。
- **再試験。** ケース ID を維持し、以前と今回の実行 ID、対象版・環境、実際の結果と証跡を対応づける。
