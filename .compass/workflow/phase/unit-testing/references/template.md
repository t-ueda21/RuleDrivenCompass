# 単体試験書

> 必須欄は確認した内容または根拠の参照先を記録する。補足欄も記録し、対象外・未確認・未実施の場合は「状態（理由）」を記入する。

## 文書管理（必須）

| 記録項目 | 内容 |
| --- | --- |
| 文書版または更新日 |  |
| 作成・更新者（該当時） |  |
| 関連資料・版の参照先（該当時） |  |

## 実行結果（必須）

> ケース ID と実行 ID を対応づけ、観測した戻り値・例外・副作用と証跡を記録する。操作後に部品の合否を判断できないときは判定不能、前提不成立で対象操作を開始できないときは実施不能として、理由を残す。

| 実行 ID | ケース ID・項目名 | 実施日時 | 対象版・環境 | 試行時の入力・手順・期待結果 | 実際の操作 | 実際の結果 | 判定 | ログ・証跡の参照先 | 原因・修正・再判定（該当時） |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
|  |  |  |  |  |  |  |  |  |  |
