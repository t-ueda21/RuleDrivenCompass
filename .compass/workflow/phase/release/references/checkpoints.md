# リリースの確認基準

- **配布内容。** 対象版、成果物、設定、README などの利用資料の版と配置先を照合する。配布対象と引き渡す範囲を特定する。
- **導入と利用。** 対象の成果物を、利用者が読む手順で確認する。実施した環境、前提、結果、確認できなかった条件を記録する。
- **判定。** 最終確認と試験結果を根拠に、対象範囲を利用可能と判定できるかを示す。既知の制約が残る場合は対象利用者への影響を示す。
- **移行・復旧。** 該当時は移行の前提、切り戻しの発動条件、判断、手順、復旧後の照合方法を定義する。実施した場合は対象版、最終状態と証跡を記録する。
- **配布・配備。** 依頼範囲に応じて実施結果を記録する。新機能・既知の制約・更新手順はリリースノートなどを参照できる状態にする。
