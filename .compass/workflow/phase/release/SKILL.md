# リリース

作業範囲に「リリース」が含まれるときに適用する。

## 成果物テンプレート

[リリース書テンプレート](references/template.md) を使って、担当範囲の成果物を作成・更新し、記録項目を確認する。レビューでは対象の成果物をテンプレートの項目と照合する。

テンプレートの必須欄に確認した内容または根拠の参照先を記録する。補足欄にも内容または適用結果と理由を記録する。完了前は[共通の記録・確認ルール](../../../documents/document-records.md)に沿って全項目を確認する。

## 実施手順

1. 配布・引き渡し対象の版、含める成果物、必要な試験結果を確認する。
2. 成果物と README などの利用資料を作成・更新し、利用者が手順をたどれる形にする。
3. 対象の成果物を利用手順に沿って確認し、利用可能な完成状態を判定する。公開・配布・配備を依頼された場合は、その範囲の実施結果と参照先を記録する。

## 必須項目

- 対象の版、成果物の一覧と配置先
- README などに記載した導入・利用手順
- 手順に沿って利用できるかの最終確認結果

## 詳細な確認

導入・利用の確認、版や配布範囲の照合、移行・切り戻しを扱うときは、[リリースの確認基準](references/checkpoints.md) を参照する。

## 完了条件

対象の成果物と利用資料が揃い、利用者が手順に沿って使えることを確認できる。確認できなかった項目は理由と影響を報告する。
