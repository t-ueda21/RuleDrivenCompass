# 報告項目と判定基準

| 項目 | 報告する内容 |
| --- | --- |
| **作業結果** | 完了した内容と残作業。成果物や変更箇所がある場合は参照先を付ける。調査では確認した事実と結論を記載する。 |
| **実施した検証と結果** | 実行したコマンドまたは確認方法、確認した範囲、結果。失敗した検証は失敗と記載し、再実行した場合は最終結果と残る問題を示す。 |
| **未実施の検証と理由** | 必要または予定していた検証のうち実施できなかった項目と、その理由。依頼や検証に関係する範囲を記載する。 |
| **未確認事項** | 判定できていない挙動、条件、適用範囲など。ユーザーの判断や完了条件に影響する場合は、その影響を示す。 |
| **次に推奨する作業** | 次に行う具体的な作業を毎回示す。追加作業が不要な場合は「追加作業なし」と明記する。 |

## 検証結果の扱い

- 実行結果を確認した場合は、実行した操作、対象版・環境、観測結果、必要な証跡を記載する。
- 確認を実施して判定できなかった場合は、実際に確認した事項と判定不能の理由を記載する。
- 確認を実施できなかった場合は、未実施の検証に理由を、未確認事項に判断が残る機能や環境を記載する。
- 再実行した場合は、最終結果と最初の失敗が解消したことを確認できる範囲を示す。
- 追加作業を推奨するときは、対象、具体的な操作、確認する結果を示す。
