# Excelのシート構成

全ブックの先頭は「タイトル」、２枚目は「変更履歴」。３枚目以降は各文書の表に示す順序で配置する。各シートに含める章は標準テンプレートの見出しで対応づける。

## 調査報告書

| シート | 対応する章 |
| --- | --- |
| 調査概要 | 調査概要 |
| 調査結果 | 確認結果と根拠<br>結論<br>未確認事項 |
| 分析・影響 | 再現確認<br>原因分析<br>実現可能性の比較<br>図・補足資料<br>影響範囲と条件<br>制約・依存・対応判断 |

## 要件定義書

| シート | 対応する章 |
| --- | --- |
| 目的・範囲 | 目的・利用者・範囲<br>要求の情報源 |
| 要件一覧 | 要件一覧<br>機能要件<br>品質要件・制約<br>データ・権限・外部連携の要求<br>運用・移行に関する要求 |
| ユースケース | ユースケースと図 |
| 画面レビュー | 画面試作とフィードバック |
| 判定条件 | 受け入れ条件<br>仮説と成功条件 |
| 要件確認 | 未確定事項と依存関係<br>要求の属性・依存と衝突<br>要件レビュー・妥当性確認 |

## 基本設計書

| シート | 対応する章 |
| --- | --- |
| 設計概要 | 設計対象と前提<br>要件との対応 |
| 構成・フロー | 構成要素と境界<br>アーキテクチャ図・画面遷移図<br>利用フロー・画面・処理の起点<br>データの流れと管理 |
| 接続契約 | 要素間の契約<br>連携条件と変更影響 |
| 品質・運用 | 品質要件と設計対策<br>配備・運用の構成 |
| 設計確認 | 設計判断と制約への対応<br>設計の確認結果 |

## 詳細設計書

| シート | 対応する章 |
| --- | --- |
| 設計概要 | 設計対象と参照資料 |

## 実装記録
